# 融合主视觉探索稿（Fusion Study）

这是首页主视觉的一次融合探索，不是已确认的最终设计，也未经过用户视觉验收。
预览控件中标注为「融合探索稿 · 材质待打磨」。

## 访问地址

- 融合稿：<http://127.0.0.1:5199/#/home?hero=fusion>
- 对照 v2：<http://127.0.0.1:5199/#/home>
- 对照 A：<http://127.0.0.1:5199/#/home?hero=a>
- 对照 B：<http://127.0.0.1:5199/#/home?hero=b>（人物剪影占位，未完成）

预览由 `frontend/vite.preview.config.mjs` 的独立设计入口提供，固定 `127.0.0.1:5199`，
不加载正式应用路由、状态库、API 客户端或正式主题。正式页面、聊天页、数据库与
`localhost:8088` 均未改动。

## 设计意图

把 v2 的柔和丝绸光场与 A 的挂件元素放进**同一个光源与材质空间**，而不是在 v2
背景上贴 A 的素材：

- 金色链条从画面上方垂落，承托缎面蝴蝶结、金色冠盖、细长切面水晶；
- 珍珠与像素爱心落在同一块丝绸上，共用左上主光、右侧补光与底部反射光；
- 在水晶下方有与光源方向一致的柔和投影、链影与接触阴影；
- 页面标题、按钮、文案全部为前端文字，素材本身不含文字或人物；
- 首页沿用 v2 的导航、字体、角色卡与功能结构；聊天页本轮未修改。

## 素材来源与能力边界

- 素材由本地 Python 3 + Pillow + NumPy 程序化生成，无 AI 图像生成、无 3D 建模/
  渲染套件、无在线素材服务。
- 参考图只用于风格分析，没有裁切、嵌入或拼贴任何原图、人物、文字或水印。
- 因为工具限制，材质无法达到高质量商业渲染的水准；以下缺陷均保留在画面中，
  没有用全局滤镜、强模糊或过曝来掩盖。

## 本轮实际修复

**已修复：水晶与金色冠盖内部的彩色噪点。**

- 原因：同一个平面被拆成两个三角形，两者的 `facet id` 逐像素竞争，导致同一
  切面内的颜色随机跳变。
- 修改：相邻共面三角形共享同一 `facet id`（`fusion_scene.py` 的 `build_polyhedron`
  与 `build_frustum`）。
- 验证：800×533 下，水晶内部相邻像素 `facet id` 变化由 4215 降到 652（只剩真实
  切面边界）；晶体内噪点消失，冠盖同步变干净。

**素材保留：**

- `frontend/preview/assets/art/hero-fusion.webp` 是修复前的原始候选，仍保留在本地，
  未覆盖、本轮未提交。
- `frontend/preview/assets/art/hero-fusion-v2.webp` 是修复后的候选，当前预览使用这一版。

## 仍然存在的视觉缺陷（未修复，供判断）

1. **蝴蝶结**：两个环状体更像高光金属/气球壳，而不是清晰折叠的缎带；结扣偏小、
   偏暗，缺少 A 中蝴蝶结的玩具感。
2. **珍珠**：五颗球体相互叠压成一团云状，缺少独立间距与各自的落影。
3. **画面上部过渡带**：远焦丝绸仍有约 7% 高度的灰紫模糊带，接近灰雾观感。
4. **水晶切面**：噪点清除后，切面边界出现虚线状浅色接缝；切面偏宽、颜色偏粉彩，
   像糖霜玻璃而非高净度水晶。
5. **丝绸**：斜向条纹与高饱和粉蓝偏“拉丝缎面”，缺少 v2 那种更柔的织物层次。
6. **像素爱心**：方块间缝隙偏大、整体偏小，更像格纹贴片；金色挂环也偏小。
7. **构图**：1440 下挂件相对面积偏小且偏右上；它与页面标题、控件的距离可用，
   但还不是最终构图。

B 的人物剪影仍是占位；本轮没有新增人物方案，也没有继续精修 B。

## 页面适配与首屏

- 融合稿在 1440×900 使用 576px 主视觉高度，角色首卡完整进入首屏；
- 1024×768 主视觉收紧到 540px，角色首卡露出约 61px（可识别名称与身份）；
- 390×844 主视觉变为 200px 横幅，素材放大并左移以避开预览控件，角色首卡露出约 75px；
- 窄屏预览面板改为 2×2 选项网格，打开时不覆盖标题、按钮或角色入口；
- 未缩小正文与导航字体，未用整页缩放换首屏空间。
