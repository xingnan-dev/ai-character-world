# 已知限制、待办与关闭条件

更新于 2026-11-22。这里区分代码缺陷、使用成本和未验证事项；没有把计划能力当成需求。当前验收摘要见 [ACCEPTANCE_STATUS.md](ACCEPTANCE_STATUS.md)。

## 本轮关闭的待办

| 分类 | 原有证据／问题 | 本轮结果与完成条件 |
| --- | --- | --- |
| 日常运行缺口 | 早期主要使用专用启动入口 | 普通 Maven、普通 Vite、独立 MySQL、真实 Provider 直连、登录／角色／聊天／刷新已通过；无需本地取证脚本才能启动 |
| 成长验证缺口 | 只有默认状态和桩更新证据 | 固定第二次反馈触发真实 `changed=true`，版本 0→1；下一新会话注入非默认状态，回复符合适应方向且身份不变。有限一次样本，不推广为长期质量保证 |
| 正确性 | 角色计划可能被提取为已发生经历 | 句级排除明确计划／猜测／传闻，独立的已确认句仍保留；修复前固定回归失败、修复后通过 |
| 正确性／可用性 | World 一个 Event 的其他句子含计划，会误拒独立已发生事实 | 以证据所在完整句判定，不再把其他独立句的标记传播给事实句；真实混合输入保存与后续使用通过 |
| 正确性 | World 短引文可能省略原句的限定语 | 保存并注入证据所在完整句，保留“据说／计划／尚未证实”等上下文；确定性回归及真实样本通过 |
| 日常日志 | 基础配置输出 SQL 明细，并可能生成无用默认账号密码 | 默认关闭 SQL 明细、使用 INFO，并排除不使用的默认 UserDetails 账号；普通登录聊天实测通过 |
| 文档 | README 测试数字与 CLAUDE 阶段／迁移范围过时 | README 指向单一验收摘要，长期约定改为当前结构与有效规则 |

本轮未发现仍阻断所述本地核心流程的已复现缺陷。缺少数据库权限、JWT、模型 Key／额度等仍是运行前提，不是用 Mock 掩盖的“已通过”。

## 影响正确性或一致性的限制

| 项目 | 已有证据与影响 | 后续完成条件 |
| --- | --- | --- |
| 旧错误记忆不自动清洗 | 早期专用失败样本保留；新校验不会回溯清理日常数据 | 明确受影响条目后通过现有更新／删除接口精确处理；不批量猜测删除 |
| 来源不是语义真值 | 角色／World 使用原文来源与保守语言规则；原始陈述仍可能错误 | 需要另定评测样本和质量目标，不能宣称模型不会出错 |
| 角色自由概括不支持 | `value` 要求原文片段；“我喝咖啡时不加糖”可保存“不加糖”，自由改写“偏好无糖咖啡”会被拒绝。这是有效概括的损失，不算拦截错误事实的成功 | 如要支持自由概括，先定义摘要与来源的独立验证／存储契约；不在本轮取消实体值校验来制造通过 |
| 混合表达仍可能少记 | 角色的假设／小说台词仍有整条跳过边界；同一句中的计划／事实仍可能保守处理 | 针对具体误拒样本修复，并保留原有事实保护测试 |
| 检索不是通用语义搜索 | 有界候选、关键词、词面、重要度和时间排序；少量自然问法通过 | 不保证任意同义改写或大规模记忆召回；没有引入向量数据库 |
| World 记忆不是即时一致 | Round 终态先提交，后处理可能尚未完成；崩溃可能遗漏提取，没有自动补偿 | 若未来业务依赖强一致／可补偿，需另行定义最小持久完成语义；当前只读 Agent 不依赖该能力 |
| 删除不等于全局遗忘 | 删除条目阻止后续检索，不删除历史聊天或已经派生的其他摘要 | 若需要全局遗忘，先定义范围；不能把条目删除验收扩写成全面遗忘通过 |

## 体验问题与有界运行限制

- 从角色详情进入聊天、或刷新后，可能需要手动选择左侧会话；本轮按此可完成真实对话与读回，未承诺自动恢复当前选择。
- 聊天后处理包含记忆、关系、成长，可能延长界面等待；World 的完成提示也不代表记忆完成。不要仅等固定秒数猜测结束。
- 停止／断开不保证 Provider 停止计算或计费；聊天不保存未完成的部分回复。
- Agent 的 FAILED／COMPLETED 为终态，Resume 仅针对后端允许的 PENDING／stale RUNNING；未持久化的模型请求恢复时可能重发。
- Agent 的上游故障代码有时仍较泛；空 Goal 的外层提示仍叫“创建请求未确认”，但校验消息明确且不发请求。
- 工具结果有字符上限，超长 JSON 可能作为安全文本显示；最近列表的大历史操作没有做压力验收。
- Sass 弃用和大 bundle 警告仍存在，当前构建成功；它们不是本轮功能阻断，也没有据此作性能保证。
